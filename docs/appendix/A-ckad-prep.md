# 附录 A 增强：CKAD 备考三件套

> 来源：[CNCF 官方考试页](https://www.cncf.io/training/certification/ckad/) · [killer.sh](https://killer.sh/) · [CKAD-exercises](https://github.com/dgkanatsios/CKAD-exercises)
> 验证环境：待验证（考试环境与考纲以官方页当日内容为准）

## 概念：为什么需要

CKAD（Certified Kubernetes Application Developer，K8s 应用开发者认证）是 2 小时实操考试，考场允许查阅官方文档——考的不是「背命令」，是「查文档的速度 + 排障思路」。备考信息鱼龙混杂（第三方课程、过期考纲、考点漂移），三件套把「信什么」收敛到三个权威入口。

- **从哪来**：网上备考资料多而杂 → 官方考纲 + 官方模拟 + 开源题库三条主线
- **是什么**：官方考试页（大纲与形式的唯一权威源）+ killer.sh（考票附赠的官方模拟）+ CKAD-exercises（按考点分类的免费题库）
- **往哪去**：考纲随考试版本调整，一切以官方页当日内容为准

## 动手：三件套使用流程

| 项 | 入口 | 用法 |
|---|---|---|
| 官方考试页 | https://www.cncf.io/training/certification/ckad/ | 大纲与形式的唯一权威源；大纲会更新，引用时标注读取日期 |
| 官方模拟环境 | https://killer.sh/ | 考票附赠的官方模拟（KillerCoda 同源）；考前一周限时完整做一遍，练的是「查文档速度」不是「背命令」 |
| 开源题库 | https://github.com/dgkanatsios/CKAD-exercises | 按考点分类免费刷题 |

**备考纪律一条**：官方 curriculum 页每次考试版本可能调整，模拟题资源（尤其第三方课程）可能出现考点漂移，一切以官方页当日内容为准。

**考前一周节奏**（步骤式，命令待验证）：
1. 第 1~3 天：对照官方考纲（cncf/curriculum）过一遍考点权重，用 CKAD-exercises 按考点分类刷题，薄弱域标记出来
2. 第 4~5 天：killer.sh 限时完整做一遍，模拟考场节奏；错题回官方文档查字段定义
3. 第 6~7 天：重做错题 + 练多集群 context 切换与 `--dry-run=client -o yaml` 模板生成（考场高频操作）

## 实用技巧

- 考场可查 https://kubernetes.io/docs/ 官方文档，平时练习就养成「查文档」习惯，别依赖记忆
- 刷题按考点分类（Core Concepts / Configuration / Pod Design 等），对照考纲权重分配时间，别平均用力
- 常见失分点：多集群 context 切换不熟、`--dry-run=client -o yaml` 生成模板不熟、探针与资源限制字段记混——这三项优先练

## 架构师视角

- 解决什么问题：备考信息收敛，避免在过期/低质资料上浪费时间
- 何时用：考前 1~2 周冲刺；日常学习阶段不需要
- 何时不用：Part 1 学习阶段——备考是检验，不是学习路径，别用刷题代替学原理
- 权衡：官方模拟（真实但次数有限）vs 免费题库（量大但非官方）——时间分配以官方模拟为主
- 固定三问（本附录对应考试平台）：平台提供了什么能力边界？（官方考纲 + 考票附赠模拟环境）业务接入点在哪？（考试报名、模拟环境使用）需要和官方对齐什么？（考纲版本与读取日期，引用时标注）
